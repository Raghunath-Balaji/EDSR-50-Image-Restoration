# Breaking the Noise: Hardware-Optimized EDSR for Speckle Super-Resolution

This repository contains our final submission for the hackathon. After extensive testing, we engineered a mathematically decoupled EDSR network that completely isolates structural edge-retention from speckle noise removal, hitting **76.53% SSIM**.

## The Architecture: Why EDSR?
Super-Resolution networks typically struggle when heavy noise is introduced. We initially tested standard U-Nets, which compress the image down into smaller latent bottlenecks (e.g., 16x16) before expanding them back up. This created a **Compression Trap**: the physical downsampling permanently destroyed the high-frequency sub-pixel details needed to upscale the image accurately, resulting in a poor 67.91% SSIM.

We pivoted to an **Enhanced Deep Super-Resolution (EDSR)** architecture because it operates entirely at the *native resolution* of the input image. By removing downsampling layers entirely and relying on a deep chain of Residual Blocks, the EDSR model preserves high-frequency structural edges perfectly. To handle the complexity of upscaling *and* denoising simultaneously, we physically decoupled the upsampling heads: one branch handles deblurring, one handles denoising, and one handles pure super-resolution. These branches only fuse at the very end, preventing capacity bottlenecks.

## The Loss Function Strategy
Speckle noise is notoriously difficult for neural networks to handle because it is **multiplicative**, not additive. Standard L1 or MSE (L2) losses often fail to converge or result in blurry textures when confronted with multiplicative variance. 

To solve this, we engineered a bespoke hybrid loss function: **85% Charbonnier Loss + 15% SSIM Loss**.

### Why Charbonnier Loss? (85%)
`Charbonnier(x, y) = sqrt((x - y)^2 + epsilon)`
Charbonnier is a differentiable variant of L1 loss. Unlike standard L2 (MSE) which heavily penalizes large outliers (causing the network to over-blur images to "play it safe" against heavy speckle noise), Charbonnier is robust to outliers. The `epsilon` term prevents the gradients from exploding near zero. It stabilizes the massive error spikes generated by multiplicative speckle noise, providing a smooth, consistent training curve.

### Why SSIM Loss? (15%)
While Charbonnier stabilizes the noise removal, it doesn't understand "structure". We injected a 15% Structural Similarity Index (SSIM) penalty directly into the loss function to force the network to care about human-perceivable edges. 

*Why only 15%?* During our ablation studies, we tested a "Nuclear" 90% SSIM loss configuration. The highly non-convex nature of SSIM gradients caused an immediate gradient explosion that shattered the network weights (resulting in a 24% SSIM collapse). By capping SSIM at 15%, it acts as a powerful regularizer—gently guiding the network to keep edges sharp without destabilizing the primary Charbonnier convergence.

## The Full Ablation Study
We did not arrive at this architecture by guessing. We systematically eliminated alternative theories:

| Model Architecture | Parameter Size | Strategy / Architecture Design | Peak SSIM (%) | Outcome / Failure Point |
| :--- | :--- | :--- | :--- | :--- |
| **SwinIR (Transformer)** | 11.9 M | Global Self-Attention | N/A | **Hardware Failure:** OOM on RTX 5050; 22hrs/epoch at Batch Size 1. |
| **U-Net (CNN)** | 31.4 M | Spatial Downsampling (16x16 Bottleneck) | 67.91% | **Compression Trap:** Sub-pixel speckle data permanently lost during downsampling. |
| **EDSR (Native Fusion)** | ~7.3 M | Unified Upsampling & Native Res Fusion | 73.12% | **Capacity Bottleneck:** Branches fought for physical weights during simultaneous upscale. |
| **EDSR (Epoch 80)** | 8.2 M | Decoupled Upsampling (Over-trained) | 75.52% | **Overfitting:** Memorized training noise distribution after Epoch 50. |
| **EDSR (Epoch 50)** | **8.2 M** | **Decoupled Upsampling + TTA (Golden)** | **76.53%** | **Optimal Champion:** Hardware-efficient, mathematically decoupled, peak generalization. |
